# 에이블리 주문 자동발송

디지털 상품(카카오톡 테마) 주문이 들어오면 사람 손 없이 끝까지 처리해요.

1. 발주 관리에서 새 주문 확인 → **상품준비중 처리**
2. 고객 메일로 다운로드 링크 발송 💌
3. 발송 관리에서 **발송 처리**

GitHub Actions 가 5분마다 대신 돌려주기 때문에 **컴퓨터를 꺼놔도** 됩니다.

## 이 저장소에 없는 것

비밀번호와 테마 다운로드 링크는 저장소에 **들어 있지 않습니다.**
전부 GitHub 시크릿(암호화)으로만 넣습니다.

| 시크릿 이름 | 내용 |
|---|---|
| `ABLY_ID` / `ABLY_PW` | 에이블리 셀러 로그인 |
| `GMAIL_ADDR` / `GMAIL_APP_PASSWORD` | 메일 보내는 계정 (네이버도 됨) |
| `THEME_LINKS_JSON` | 테마 이름 → 다운로드 링크 표 |

## 안전장치

- **이메일을 안 적었거나 링크가 없는 주문**은 아무것도 건드리지 않고 `보류_수동처리.csv` 로 빼둡니다.
- **중복 발송 차단** — 보낸편지함을 뒤져 이미 보낸 주문은 건너뜁니다.
  확인할 방법이 하나도 없으면 보내지 않고 멈춥니다.
- **화면에 안 보이는 주문은 처리하지 않습니다** — 엑셀에 지난 주문이 섞여 와도
  지금 화면 목록과 대조해서 걸러냅니다.
- 실패하면 그 순간 화면을 스크린샷으로 남깁니다.

## 직접 돌려보기

```bash
pip install -r requirements.txt
python -m playwright install chromium

python 에이블리_세션저장.py      # 처음 한 번, 로그인
python 에이블리_전자동.py        # 연습 — 계획만 보여주고 아무것도 안 해요
python 에이블리_전자동.py --진짜  # 진짜로 처리
```

`설정_예시.json` 을 복사해 `설정.json` 을 만들고 채우면 로컬에서도 돕니다.
